How the rack display works
One page, two audiences: a browser on the LAN
and a 1440×240 DisplayLink panel in the rack.

Web server

Headless Chromium (chromedp)

Opens the same page a browser sees and screenshots it once a second.
recycled every 6 h to cap memorytini reaps the orphans

DRM/KMS output

Straight to the kernel, no X or Wayland. 1440×480 buffer (udl's minimum), only the top 240 rows flushed.

udl.ko

turing01-04 kernel · built out of tree from kernel.org 6.1 sources · DKMS
DisplayLink's own evdi driver can't drive this older DL-1x5 chip; the in-kernel udl driver can.
